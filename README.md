# Virginia Police Academy Guide

A reading-first, bilingual nonfiction book project for a prospective Virginia law-enforcement recruit, with particular context for James City County and the Hampton Roads Criminal Justice Training Academy (HRCJTA).

**English working title:** *Police Academy: A 19-Week Guide to Becoming a Virginia Law Enforcement Officer*  
**Spanish working title:** *Academia de Policía: Guía de 19 Semanas para Convertirse en Oficial de Policía en Virginia*

This foundation contains publication structure—not finished academy guidance. English is the canonical research language; Spanish follows factual review as a natural adaptation. The numbered weeks are an **editorial learning journey**, not a representation of HRCJTA's unpublished schedule.

## Start

Read [START-HERE.md](START-HERE.md), then the language-specific front matter. Build with:

```sh
./scripts/build-pdf.sh en
./scripts/build-pdf.sh es
```
