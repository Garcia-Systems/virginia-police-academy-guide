# Research Sources

This directory stores shared research metadata and notes, not a second manuscript. Follow `docs/SOURCING.md`.

- `shared/source-register.md`: one canonical bibliographic record per reviewed source.
- `shared/research-log.md`: questions, checks, conflicts, effective dates, and chapter relevance.

Do not add a citation until a contributor has opened and verified the source. No substantive sources are asserted in this foundation PR; later research PRs will populate the register.
