# Start Here

This repository is a bilingual publishing system and editorial map. It is intentionally not a completed book.

1. Review `frontmatter/en/ABOUT-THIS-BOOK.md` for scope and disclaimers.
2. Treat English as canonical: **research → English draft → factual review → stable English chapter → Spanish adaptation**.
3. Use `templates/CHAPTER_TEMPLATE.en.md` and its Spanish companion.
4. Record shared research once under `sources/shared/`; cite locatable sources in every substantive chapter.
5. Never convert the editorial week labels into claims about an academy schedule without authoritative evidence.
6. Build both editions before review and inspect the validation output.

Contributors should read every guide in `docs/` before drafting.
